# Domus – Back-end

API REST para controle financeiro pessoal.

## Stack
- Java 17
- Spring Boot
- Spring Security (JWT)
- PostgreSQL

## Autenticação
- JWT Bearer Token
- Rotas protegidas

## Endpoints principais
- /api/auth
- /api/dashboard
- /api/income
- /api/costs
- /api/investments

## Rodando localmente
./mvnw spring-boot:run
